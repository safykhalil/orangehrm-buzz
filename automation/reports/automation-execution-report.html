TC-008's cleanup records drift separately if the Like count after its own reversal differs from baseline.

Cleanup timing (Hard Rule 5): the worst-case TC-008 reversal budget is 3 attempts × 33 s + 2 × 2 s delay = 103 s, and the afterEach hook raises its own timeout to 130 s. A check that runs when the spec file loads enforces budget < hook timeout. A probe on Playwright 1.63 confirmed that without this, an afterEach overrunning the config timeout is killed mid-cleanup.
